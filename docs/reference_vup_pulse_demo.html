VUP Pulse

Demo values – final numbers come from the full run

Where and for whom do VUP payments arrive late? A tool for planners, built on NISR household survey data.

Read this first: this site shows patterns in the data. It cannot tell why a payment was late. Use it to decide where to investigate.

Source: NISR VUP household survey microdata. Delay = average days late of the last payments, as reported by households. Early, unweighted values for design review only.
